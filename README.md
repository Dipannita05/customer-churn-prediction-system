# Customer Churn Prediction System

## Project Overview

Customer churn is a major challenge in the banking industry, as losing existing customers directly impacts profitability and long-term growth. This project presents an end-to-end Customer Churn Prediction System that combines Machine Learning, MySQL, Power BI, Streamlit, and Google Gemini AI to identify customers at risk of leaving and provide actionable retention strategies.

Developed as a Project-Based Learning (PBL) project for B.Sc. Data Science, the solution transforms raw customer data into predictive insights, interactive dashboards, and real-time decision support tools.

## Objectives

* Predict customer churn using Machine Learning models.
* Identify key factors influencing customer attrition.
* Provide interactive business intelligence dashboards.
* Generate AI-powered customer retention recommendations.
* Enable real-time churn prediction through a web application.

## Technologies Used

* Python
* MySQL
* Power BI
* Streamlit
* Scikit-learn
* XGBoost
* SMOTE
* Google Gemini AI

## Dataset

The project uses the Bank Customer Churn Modelling dataset containing 10,000 customer records and demographic, financial, and behavioral attributes.

## Machine Learning Models

The following models were developed and evaluated:

* Logistic Regression
* Decision Tree
* Random Forest
* XGBoost

Random Forest was selected as the final model based on its strong overall performance and AUC score.

## Key Features

* Customer churn prediction
* Data preprocessing and feature engineering
* Class imbalance handling using SMOTE
* Exploratory Data Analysis (EDA)
* Interactive Power BI dashboard
* Streamlit web application
* AI-generated retention recommendations

## Power BI Dashboard

The Power BI dashboard provides visual insights into:

* Churn distribution
* Geographic analysis
* Gender analysis
* Age-based churn trends
* Customer activity analysis
* Business KPIs

## Streamlit Web Application

The web application allows users to:

* Enter customer details
* Predict churn probability
* View risk classification
* Generate AI-powered retention recommendations

## Project Outcomes

* Achieved high predictive performance using Machine Learning.
* Identified age, number of products, and account balance as major churn indicators.
* Developed a complete decision-support system for customer retention.
* Integrated analytics, machine learning, visualization, and AI into a single workflow.

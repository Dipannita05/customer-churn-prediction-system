# 🤖 Customer Churn Prediction System

## 📌 Project Overview

Customer churn is a major challenge in the banking industry, as losing existing customers can impact profitability and long-term growth. This project presents an **end-to-end Customer Churn Prediction System** that combines **Machine Learning, MySQL, Power BI, Streamlit, and Google Gemini AI** to identify customers at risk of leaving and provide actionable retention strategies.

Developed as a **Project-Based Learning (PBL) project for B.Sc. Data Science**, the solution transforms raw customer data into predictive insights, interactive dashboards, and real-time decision-support tools.

## 🎯 Objectives

* Predict customer churn using Machine Learning models.
* Identify key factors influencing customer attrition.
* Provide interactive Business Intelligence dashboards.
* Generate AI-powered customer retention recommendations.
* Enable real-time churn prediction through a web application.
* Integrate Machine Learning, database management, visualization, and AI into a unified workflow.

## 🗃️ Dataset

The project uses the **Bank Customer Churn Modelling dataset**, containing **10,000 customer records** with demographic, financial, and behavioral attributes.

The dataset was processed and prepared for exploratory analysis and machine learning-based churn prediction.

## 🧹 Data Preprocessing & Feature Engineering

The machine learning workflow included:

* Data cleaning and preprocessing
* Feature selection and transformation
* Encoding of categorical variables
* Feature engineering
* Handling class imbalance using **SMOTE**
* Preparation of training and testing datasets

## 🤖 Machine Learning Models

The following models were developed and evaluated:

* Logistic Regression
* Decision Tree
* Random Forest
* XGBoost

**Random Forest** was selected as the final model based on its strong overall performance, achieving approximately **89.4% accuracy** and an **AUC score of 0.9626**.

## 📊 Exploratory Data Analysis

EDA was performed to understand customer behavior and identify patterns associated with churn.

The analysis included:

* Churn distribution
* Geographic analysis
* Gender-based analysis
* Age-based churn trends
* Customer activity analysis
* Product and account-related patterns
* Correlation analysis

## 📈 Power BI Dashboard

An interactive Power BI dashboard was developed to provide business-oriented insights into customer churn.

### 🔢 Dashboard Analysis

The dashboard provides visual insights into:

* Churn distribution
* Geographic analysis
* Gender analysis
* Age-based churn trends
* Customer activity analysis
* Business KPIs

The dashboard helps users identify patterns in customer churn and understand the characteristics of customers at higher risk of attrition.

## 🌐 Streamlit Web Application

A Streamlit-based web application was developed to provide an interactive interface for real-time churn prediction.

The application allows users to:

* Enter customer details
* Generate churn predictions
* View predicted churn risk
* Generate AI-powered retention recommendations

## 🧠 AI-Powered Retention Recommendations

Google Gemini AI was integrated into the system to generate **customer retention recommendations** based on the predicted churn risk and customer information.

This extends the system beyond prediction by providing actionable suggestions that can support customer retention strategies.
